# 数据库配置说明

## 当前配置

配置文件位置：`App/Config/AppConfig.json5`（独立文件夹，便于直接修改）

```json
{
  "Database": {
    "DbType": "SqlServer",
    "ConnectionString": "Server=localhost;Database=DTDJJ_DB;User Id=sa;Password=123456;TrustServerCertificate=True;",
    "IsAutoCloseConnection": true
  }
}
```

## 配置参数说明

### DbType
数据库类型，支持：
- `SqlServer` - Microsoft SQL Server
- `MySql` - MySQL数据库
- `Sqlite` - SQLite数据库
- `PostgreSQL` - PostgreSQL数据库
- `Oracle` - Oracle数据库

### ConnectionString
数据库连接字符串

**SQL Server 连接字符串格式：**
```
Server=服务器地址;Database=数据库名;User Id=用户名;Password=密码;TrustServerCertificate=True;
```

**参数说明：**
- `Server`: 数据库服务器地址
  - `localhost` - 本地服务器
  - `127.0.0.1` - 本地IP
  - `192.168.1.100` - 局域网IP
  - `server.domain.com` - 域名
- `Database`: 数据库名称（默认：`DTDJJ_DB`）
- `User Id`: 登录用户名（默认：`sa`）
- `Password`: 登录密码（默认：`123456`，请修改为实际密码）
- `TrustServerCertificate`: 信任服务器证书（True/False）

### IsAutoCloseConnection
是否自动关闭连接
- `true` - 每次操作后自动关闭连接（推荐，节省资源）
- `false` - 保持连接打开（适合高频操作）

## 使用 Windows 身份验证

如果使用 Windows 身份验证而不是 SQL Server 身份验证：

```json
{
  "Database": {
    "DbType": "SqlServer",
    "ConnectionString": "Server=localhost;Database=DTDJJ_DB;Integrated Security=True;TrustServerCertificate=True;",
    "IsAutoCloseConnection": true
  }
}
```

## 数据库初始化步骤

### 1. 创建数据库
在 SQL Server Management Studio (SSMS) 中执行：

```sql
CREATE DATABASE DTDJJ_DB;
GO

USE DTDJJ_DB;
GO
```

### 2. 执行建表脚本
运行 `UserPermission.sql` 脚本创建表结构和默认数据：

```sql
-- 在 SSMS 中打开 UserPermission.sql 文件并执行
```

或者让程序自动创建（推荐）：
- 程序启动时会自动调用 `UserService` 的 `InitializeDatabase()` 方法
- 自动创建 Users 表
- 自动插入默认用户（admin、engineer、operator）

### 3. 验证数据库连接
启动程序后查看日志：
```
已创建默认用户账户：admin/engineer/operator，密码均为：admin（注：旧 SQL Server 版默认密码为 admin123，当前 PostgreSQL 版默认密码为 admin）
```

## 常见问题

### 1. 连接失败：登录失败
**原因：** 用户名或密码错误

**解决：**
- 检查 SQL Server 是否启用了 SQL Server 身份验证
- 在 SSMS 中：服务器属性 → 安全性 → SQL Server 和 Windows 身份验证模式
- 确认 sa 账户已启用且密码正确

### 2. 连接失败：服务器不存在或拒绝访问
**原因：** SQL Server 服务未启动或网络配置问题

**解决：**
- 检查 SQL Server 服务是否运行
- 启用 TCP/IP 协议：SQL Server Configuration Manager → SQL Server 网络配置 → TCP/IP
- 检查防火墙设置（默认端口 1433）

### 3. 证书验证失败
**原因：** SSL 证书问题

**解决：**
- 确保连接字符串包含 `TrustServerCertificate=True;`

### 4. 数据库不存在
**原因：** 数据库未创建

**解决：**
- 在 SSMS 中手动创建数据库 `DTDJJ_DB`
- 或修改配置文件中的数据库名称为已存在的数据库

## 修改配置

修改配置文件后需要：
1. 保存文件
2. 重启应用程序
3. 查看日志确认连接成功

## 安全建议

⚠️ **生产环境安全配置：**

1. **不要使用 sa 账户**
   - 创建专用数据库用户
   - 只授予必要的权限（SELECT, INSERT, UPDATE, DELETE）

2. **使用强密码**
   - 修改默认密码 `123456`
   - 使用复杂密码（大小写字母+数字+特殊字符）

3. **加密连接字符串**
   - 考虑使用配置加密
   - 不要将密码提交到版本控制系统

4. **定期备份**
   - 设置自动备份计划
   - 定期测试恢复流程
