# 用户权限管理数据库设计说明

## 数据库类型
SQL Server

## 表结构设计

### 1. Users（用户表）- 核心表

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| Id | INT | PRIMARY KEY, IDENTITY(1,1) | 用户ID，主键，自增 |
| UserName | NVARCHAR(50) | NOT NULL, UNIQUE | 用户名，唯一，用于登录 |
| RealName | NVARCHAR(50) | NOT NULL | 真实姓名，用于显示 |
| FingerprintId | NVARCHAR(50) | NULL, UNIQUE | 指纹ID，唯一，用于指纹登录 |
| Password | NVARCHAR(100) | NULL | 密码（SHA256加密），用于密码登录 |
| Role | INT | NOT NULL, DEFAULT 0 | 角色：0=操作员, 1=工程师, 2=管理员 |
| IsEnabled | BIT | NOT NULL, DEFAULT 1 | 是否启用：1=启用, 0=禁用 |
| CreatedAt | DATETIME | NOT NULL, DEFAULT GETDATE() | 创建时间 |
| UpdatedAt | DATETIME | NULL | 最后更新时间 |
| LastLoginAt | DATETIME | NULL | 最后登录时间 |
| Remark | NVARCHAR(200) | NULL | 备注信息 |

**索引：**
- `IX_Users_FingerprintId`: 指纹ID索引，加速指纹登录查询
- `IX_Users_Role`: 角色索引，加速按角色筛选
- `IX_Users_IsEnabled`: 启用状态索引

### 2. LoginLogs（登录日志表）- 可选

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| Id | INT | PRIMARY KEY, IDENTITY(1,1) | 日志ID，主键，自增 |
| UserId | INT | NOT NULL, FK | 用户ID，外键关联Users表 |
| UserName | NVARCHAR(50) | NOT NULL | 用户名（冗余字段，便于查询） |
| LoginType | NVARCHAR(20) | NOT NULL | 登录方式：Password/NFC |
| LoginTime | DATETIME | NOT NULL, DEFAULT GETDATE() | 登录时间 |
| LogoutTime | DATETIME | NULL | 登出时间 |
| LogoutType | NVARCHAR(20) | NULL | 登出方式：Manual/Auto |
| IpAddress | NVARCHAR(50) | NULL | IP地址（可选） |
| IsSuccess | BIT | NOT NULL, DEFAULT 1 | 是否成功：1=成功, 0=失败 |
| FailReason | NVARCHAR(200) | NULL | 失败原因 |

**索引：**
- `IX_LoginLogs_UserId`: 用户ID索引
- `IX_LoginLogs_LoginTime`: 登录时间索引

### 3. PermissionChangeLogs（权限变更日志表）- 可选

| 字段名 | 数据类型 | 约束 | 说明 |
|--------|---------|------|------|
| Id | INT | PRIMARY KEY, IDENTITY(1,1) | 日志ID，主键，自增 |
| UserId | INT | NOT NULL, FK | 被修改用户ID |
| UserName | NVARCHAR(50) | NOT NULL | 被修改用户名 |
| OldRole | INT | NOT NULL | 原角色 |
| NewRole | INT | NOT NULL | 新角色 |
| OperatorId | INT | NULL | 操作人ID |
| OperatorName | NVARCHAR(50) | NULL | 操作人姓名 |
| ChangeTime | DATETIME | NOT NULL, DEFAULT GETDATE() | 变更时间 |
| Remark | NVARCHAR(200) | NULL | 备注 |

**索引：**
- `IX_PermissionChangeLogs_UserId`: 用户ID索引
- `IX_PermissionChangeLogs_ChangeTime`: 变更时间索引

## 角色权限说明

### 角色类型（Role字段）

| 值 | 角色名称 | 权限范围 |
|----|---------|---------|
| 0 | 操作员 | 主页面、信息统计、报警页面、用户帮助、人员界面（密码登录/指纹登录） |
| 1 | 工程师 | 操作员权限 + 配置页面 |
| 2 | 管理员 | 所有界面（完全权限） |

## 安全特性

1. **密码加密**：使用SHA256哈希算法加密存储
2. **自动登出**：无操作超过3分钟自动登出
3. **审计日志**：记录所有登录和权限变更操作
4. **唯一性约束**：用户名和卡号必须唯一
5. **软删除支持**：通过IsEnabled字段实现禁用而非删除

## 默认账户

系统初始化时会创建三个默认账户：

| 用户名 | 真实姓名 | 卡号 | 密码 | 角色 |
|--------|---------|------|------|------|
| admin | 系统管理员 | ADMIN001 | admin123 | 管理员 |
| engineer | 工程师 | ENG001 | admin123 | 工程师 |
| operator | 操作员 | OPR001 | admin123 | 操作员 |

**注意：** 首次部署后请立即修改默认密码！

## 使用场景

### 1. 密码登录
```sql
-- 根据用户名查询用户
SELECT * FROM Users 
WHERE UserName = @UserName 
  AND IsEnabled = 1;

-- 验证密码后更新最后登录时间
UPDATE Users 
SET LastLoginAt = GETDATE() 
WHERE Id = @UserId;

-- 记录登录日志
INSERT INTO LoginLogs (UserId, UserName, LoginType, LoginTime, IsSuccess)
VALUES (@UserId, @UserName, 'Password', GETDATE(), 1);
```

### 2. 指纹登录
```sql
-- 根据指纹ID查询用户
SELECT * FROM Users 
WHERE FingerprintId = @FingerprintId 
  AND IsEnabled = 1;

-- 更新最后登录时间
UPDATE Users 
SET LastLoginAt = GETDATE() 
WHERE Id = @UserId;

-- 记录登录日志
INSERT INTO LoginLogs (UserId, UserName, LoginType, LoginTime, IsSuccess)
VALUES (@UserId, @UserName, 'NFC', GETDATE(), 1);
```

### 3. 修改用户权限
```sql
-- 记录权限变更日志
INSERT INTO PermissionChangeLogs (UserId, UserName, OldRole, NewRole, OperatorId, OperatorName, ChangeTime)
VALUES (@UserId, @UserName, @OldRole, @NewRole, @OperatorId, @OperatorName, GETDATE());

-- 更新用户角色
UPDATE Users 
SET Role = @NewRole, 
    UpdatedAt = GETDATE() 
WHERE Id = @UserId;
```

### 4. 自动登出
```sql
-- 记录登出日志
UPDATE LoginLogs 
SET LogoutTime = GETDATE(), 
    LogoutType = 'Auto' 
WHERE UserId = @UserId 
  AND LogoutTime IS NULL;
```

## 数据库连接配置

在 `App/Config/AppConfig.json5`（独立配置文件夹）中配置SQL Server连接：

```json
{
  "Database": {
    "DbType": "SqlServer",
    "ConnectionString": "Server=localhost;Database=YourDatabaseName;User Id=sa;Password=YourPassword;TrustServerCertificate=True;"
  }
}
```

## 维护建议

1. **定期清理日志**：建议每月清理3个月前的登录日志
2. **备份策略**：每天备份Users表，每周备份日志表
3. **性能监控**：监控索引使用情况，必要时添加复合索引
4. **安全审计**：定期检查权限变更日志，发现异常操作
