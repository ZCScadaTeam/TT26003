# 快速开始指南

## 🚀 5 分钟创建你的第一个 DLL

### 第一步：创建项目文件

1. 在 `@Core` 目录下创建你的项目文件夹，例如 `MyLib`
2. 创建 `.csproj` 文件（复制 `MyCustomLib.csproj` 并修改名称）
3. 创建你的 `.cs` 代码文件

### 第二步：编写代码

```csharp
namespace ZC.MyLib;

public class MyClass
{
    public string SayHello(string name)
    {
        return $"Hello, {name}!";
    }
}
```

### 第三步：编译 DLL

**方法 A：使用脚本（推荐）**
```bash
# 双击运行 build-and-publish.bat
# 或在命令行中执行
build-and-publish.bat
```

**方法 B：手动编译**
```bash
dotnet build -c Release
copy bin\Release\net10.0\ZC.MyLib.dll ..\..\-\libs\Core\
```

### 第四步：在 App 中使用

**开发阶段（推荐）：**

在 `App/App.csproj` 中添加：
```xml
<ItemGroup>
    <ProjectReference Include="../@Core/MyLib/MyLib.csproj"/>
</ItemGroup>
```

**发布阶段：**

在 `App/App.csproj` 中添加：
```xml
<ItemGroup Condition="'$(CoreLibDllPath)'!=''">
    <Reference Include="$(CoreLibDllPath)/ZC.MyLib.dll"/>
</ItemGroup>
```

### 第五步：编写代码使用

```csharp
using ZC.MyLib;

var myClass = new MyClass();
string message = myClass.SayHello("World");
Console.WriteLine(message); // 输出: Hello, World!
```

## 🔧 .csproj 配置速查

### 最小配置
```xml
<Project Sdk="Microsoft.NET.Sdk">
    <PropertyGroup>
        <TargetFramework>net10.0</TargetFramework>
        <AssemblyName>ZC.MyLib</AssemblyName>
        <RootNamespace>ZC.MyLib</RootNamespace>
    </PropertyGroup>
</Project>
```

### 引用 Core DLL
```xml
<PropertyGroup>
    <CoreLibPath>../../-/libs/Core</CoreLibPath>
</PropertyGroup>

<ItemGroup Condition="'$(CoreLibPath)' !=''">
    <Reference Include="$(CoreLibPath)/ZC.Core.dll"/>
</ItemGroup>
```

### 引用 NuGet 包
```xml
<ItemGroup>
    <PackageReference Include="Newtonsoft.Json" Version="$(NewtonsoftJsonVersion)"/>
</ItemGroup>
```

### 自动发布到 libs
```xml
<Target Name="CopyToLibs" AfterTargets="Build" Condition="'$(Configuration)' == 'Release'">
    <Copy SourceFiles="$(OutDir)$(AssemblyName).dll" 
          DestinationFolder="../../-/libs/Core/" 
          OverwriteReadOnlyFiles="true"/>
</Target>
```

## 📦 命名规范

| 类型 | 命名示例 | 说明 |
|------|---------|------|
| 项目文件夹 | `MyLib` | 简短清晰 |
| .csproj 文件 | `MyLib.csproj` | 与文件夹同名 |
| AssemblyName | `ZC.MyLib` | 加 ZC 前缀 |
| Namespace | `ZC.MyLib` | 与 AssemblyName 一致 |
| DLL 文件 | `ZC.MyLib.dll` | 自动生成 |

## 🐛 常见问题

### Q1: 编译错误 "找不到类型或命名空间"
**解决：** 检查 `CoreLibPath` 路径是否正确，确保引用的 DLL 存在

### Q2: App 运行时找不到 DLL
**解决：** 
- 使用项目引用（ProjectReference）而不是 DLL 引用
- 或确保 DLL 已复制到 App 的输出目录

### Q3: 无法调试自定义库代码
**解决：** 
- 使用项目引用而不是 DLL 引用
- 确保 .pdb 文件和 .dll 在同一目录

### Q4: 版本号如何管理
**解决：** 在 `Directory.Build.props` 中统一管理版本号
