# THA26001 上位机：按新协议重建业务逻辑

## Context（背景）

上一轮已完成"移除业务逻辑保留 UI 壳 + DemoData 假数据"（构建通过、运行验证正常）。本轮按用户上传的《THA26001 PLC ModbusTCP 采集规范》重建真实业务：

- **PLC 采集**：ModbusTCP（%MW 保持寄存器，功能码 03），心跳 %MW101 每 0.5s 写 1；轮询 %MW100 触发，==1 时采集产品1（%MW1xxx）/产品2（%MW2xxx）双通道，完成后写 0
- **数据库**：本地 SQLite（SqlSugar + Microsoft.Data.Sqlite，NuGet 均已有），CodeFirst 建表
- **登录**：无 MES 刷卡 → 角色下拉框直接选择登录；未以技术员及以上身份登录不能进配置页
- **配置页**：仅保留 PLC 通讯地址（IP+端口）；配方管理整体删除
- **站别**：默认 All，启动不再弹工位选择，直接进主程序
- **主页**：产品1/产品2 双通道实时卡片 + 检测历史表
- **统计页**：删"稼动率看板/综合效率"两个子页，数据概览改 SQLite 真数据；导出列头按用户指定
- **监控页**：改为新协议信号表（%MW100/101 + 产品1/2 各字段）

已确认的解析口径：数值字段（2 WORD）按 IEEE754 大端解析（用户确认"用 hsl 里的 float 读"，实施采用整块读+手工大端解析以规避 HSL 默认 CDAB 字序问题）；针高 = 鱼眼针高1~4 + 框口针高1~4（协议表实际到 Pin4），两种都导出。

## 一、新增文件

### 1. `App\Ext\DbModels\ThaProductRecord.cs` — SQLite 表实体
- `[SugarTable("ThaProductRecord")]` + 时间/产品码索引
- `Id`（long 雪花主键，`SnowFlakeSingle.Instance.NextId()`）
- `Channel`（1/2）、`ProductCode`（12 位串）、`CodeGrade`（int 1=A/2=B）
- `OverallResult/WithstandResult/PinHeightResult/PositionResult/ScanResult`（int 1=OK/2=NG）
- `IsRetest`（int 1=是/2=否）
- `EyeletPinHeight1~4`（鱼眼，MW1008/1012/1016/1020）、`FramePinHeight1~4`（框口，MW1010/1014/1018/1022）
- `PositionX1~X8`、`PositionY1~Y8`（MW1024~1054）
- `CreateTime`、`UpdateTime?`

### 2. `App\Services\ThaPlcService.cs` — PLC 采集服务（协议核心）
- `[AddToIOC(Singleton)] partial class ThaPlcService() : MainTaskService("THA26001-PLC"), IAutoStartTaskService`（框架自动启动，沿用旧 PlcServiceNew 模式）
- `Main(ctk)` 单线程主循环（HSL client 非线程安全，全部 IO 串行）：
  1. 断线 → `ConnectServer()` 重试（退避 3s，`SetPersistentConnection` 长连接）；`NotifyConfigChanged()` 热重连
  2. 每 0.5s：`Write("101", 1)` 心跳 → `ReadInt16("100")` 读触发
  3. 触发==1：`Read("1000", 66)` + `Read("2000", 66)` 整块读原始字节（各重试 3 次）→ `Write("100", 0)` 复位（无论解析成败都复位）→ 解析 → 落库 → 事件
- **手工解析（不用 HSL ReadFloat，规避默认 CDAB 字序）**：
  - 状态字（MW1000~1006，字节偏移 0,2,...,12）：`v = raw[o]<<8 | raw[o+1]`
  - float（大端 ABCD）：字节偏移 16,20,...,44（鱼眼/框口×4）、48,52,...,108（位置度×16）；`BitConverter.ToSingle(new[]{raw[o+3],raw[o+2],raw[o+1],raw[o]},0)`
  - 产品码：raw[120..131] 12 字节 ASCII 逐字节拼串
  - 产品2 同构（基址 2000）；`ThaProtocol.Parse(channel, raw)` 纯静态函数 + `SWAP_WORD_ORDER` 常量开关备用
- `event Action<ThaProductRecord>? OnProductRecord`（PLC 线程触发，订阅方须 Dispatcher.UIThread）
- 不可变快照 `Snapshot`（IsConnected/UpdateTime/Trigger/Heartbeat/Product1/Product2 通道数据），供监控页/主页只读轮询
- 地址基：HSL 默认 `AddressStartWithZero=true`，"1008" 直读 MW1008（联调若错位首查此项）

### 3. `App\Services\ThaDb.cs` — SQLite 入口
- `Init(cfg)`：`Directory.CreateDirectory(AppData)` → 连接串 `DataSource=<绝对路径>\AppData\THA26001.db` 回写 AppConfig → `SqlSugarScope`（IsAutoCloseConnection、InitKeyType.Attribute）→ `PRAGMA journal_mode=WAL` → `CodeFirst.InitTables<ThaProductRecord>()`
- `InsertRecords(params ThaProductRecord[])`：雪花 Id + CreateTime + Insertable

### 4. UI 行模型
- `App\UI\Pages\Main\ThaChannelCard.cs`：`[ObservableObject]`，ChannelTitle/ProductCode/码等级/总结果(大字+颜色)/各分项结果 Text+Color —— 主页双通道卡片
- `App\UI\Pages\Main\ThaHistoryRow.cs`：`[ObservableObject]`，Time/Channel/ProductCode/CodeGrade/Overall/Withstand/PinHeight/Position/Scan/Retest（全 string）—— 主页历史表 + 统计页明细表复用
- 监控页复用现有 `MonitorSignalRow`（五列结构完全匹配）

## 六、风险

1. **float 字节序**（最高风险）：协议称大端但 HSL 默认 CDAB —— 手工 ABCD 解析规避，留 SWAP_WORD_ORDER 开关联调可切
2. **%MW 地址基**（0 基假设若错则全 -1）：模拟器第一步先验证 MW100 触发通路定位
3. **心跳与采集竞态**：采集期间心跳停 1~2 周期，首版同线程串行，联调观察；必要时拆独立心跳任务
4. **UseDatabase 闭源行为**：`ThaDb.Init` 建目录须在 UseDatabase 之前；UseDatabase 包 try/catch
5. **json5 模板回归**：TaskServiceHostOptions 节误删会启动异常，模板保留
6. **监控页 66 行 500ms 刷新**：值变化才赋值（`if (row.Value != v)`）防掉帧
7. 导出列头按用户指定不含码等级/总结果/导通耐压/通道列；数据库与明细表含全字段，后续需要可加列
